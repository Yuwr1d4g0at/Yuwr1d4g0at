# Pixel Quest: how this profile works

Everything you see on the profile is generated by `scripts/build.mjs` and redrawn by the
**Update pixel profile** workflow: every day at 03:17 UTC, whenever you change `profile.json`,
`data/` or `scripts/`, and whenever someone signs the guestbook. You can also run it by hand from
the Actions tab.

## Things you can change

Edit `profile.json`:

| Key | What it does |
| --- | --- |
| `displayName`, `class`, `alignment` | The banner text. |
| `bio` | Lines in the BIO panel (4 to 5 fit nicely). |
| `inventory` | Tech stack slots: a short `label` and a `color` each. |
| `season` | `auto` picks a theme by date: Halloween (October), winter (Dec 1 to Jan 6), Valentine's (Feb 7 to 14) and your GitHub birthday week. Set a theme name to force it, or `off`. |
| `website` | Where the VISIT WEBSITE button goes. Leave empty to use the website set on `websiteRepo`, or that repo itself. |
| `hiddenRepos`, `maxQuests` | Which repos stay out of the quest log, and how many show. |
| `guestbookRows` | How many signatures the guestbook board shows. |

Tips of the day live in `data/tips.json`; one is picked per day.

## The goat

The goat levels up with your all-time contributions (level = √(XP ÷ 5) + 1) and evolves:

- **LV 10**: scarf
- **LV 20**: wizard hat
- **LV 30**: crown

On the world map it grazes your last year of contributions, one day at a time.

## Achievements

Twelve achievements unlock from your real activity: commits, pull requests, streaks, stars,
public repos, account age, guestbook signatures and level. They're listed in
`scripts/lib/panels.mjs` under `ACHIEVEMENTS` if you want to add your own.

## Guestbook

SIGN GUESTBOOK opens an issue form. The workflow thanks the visitor, closes the issue and puts them
on the board. To remove a signature, reopen the issue and close it as **not planned**, or add the
`hidden` label.

## IT help requests

ASK FOR IT HELP opens an issue form (labelled `it-help`) that warns people not to post private
info. These issues stay open for you to answer.

## Preview locally

```bash
DEMO=1 OUT_DIR=preview node scripts/build.mjs
```

Add `DEMO_LEVEL=20` or `DEMO_SEASON=winter` to preview evolutions and themes.
