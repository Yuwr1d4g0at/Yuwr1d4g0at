# Pixel Quest: how this profile works

Everything you see on the profile is generated by `scripts/build.mjs` and redrawn by the
**Update pixel profile** workflow: every day at 03:17 UTC, whenever you change `profile.json`,
`data/` or `scripts/`, and whenever someone signs the guestbook or presses a button. You can also run it by hand from
the Actions tab.

## Things you can change

Edit `profile.json`:

| Key | What it does |
| --- | --- |
| `displayName`, `class`, `alignment` | The banner text. |
| `bio` | Lines in the BIO panel (4 to 5 fit nicely). |
| `inventory` | Tech stack slots: a short `label` and a `color` each. |
| `season` | `auto` picks a theme by date: Halloween (October), winter (Dec 1 to Jan 6), Valentine's (Feb 7 to 14) and your GitHub birthday week. Set a theme name to force it, or `off`. |
| `website` | Where the "my website" link goes. Leave empty to use the website set on `websiteRepo`, or that repo itself. |
| `goatBorn` | When the goat's care meters started (at 80). |
| `encounters` | `true` shows a daily wild encounter in the banner. |
| `hiddenRepos`, `maxQuests` | Which repos stay out of the quest log, and how many show. |
| `guestbookRows` | How many signatures the guestbook board shows. |

Tips of the day live in `data/tips.json`; one is picked per day.

## The goat

The goat levels up with your all-time contributions (level = √(XP ÷ 5) + 1) and evolves:

- **LV 10**: scarf
- **LV 20**: wizard hat
- **LV 30**: crown

On the world map it grazes your last year of contributions, one day at a time.

## Achievements

Sixteen achievements unlock from your real activity: commits, pull requests, streaks, stars,
public repos, account age, guestbook signatures, level, goat feeding, bosses slain and
late-night or early-morning commits. They're listed in
`scripts/lib/panels.mjs` under `ACHIEVEMENTS` if you want to add your own.

## The buttons: feed, pet, attack

Each button opens a pre-filled issue (`[FEED]`, `[PET]` or `[ATTACK]`). When the visitor submits
it, the workflow replies with what happened, closes the issue and redraws the profile.

- **Goat care**: FOOD and LOVE start at 80 (`goatBorn` in `profile.json`) and drop by 1 point every
  3 hours. A feed adds 20 food, a pet adds 15 love. The goat's mood bubble in the banner shows how
  it's doing. Top fans are listed by feeds plus pets.
- **Boss fight**: each attack does 10 to 20 damage, and 1 in 8 is a double-damage crit. Six bosses
  (NULL POINTER up to HEISENBUG) come back tougher after the sixth.
- **Cooldowns** stop button spam: 30 min between feeds, 10 between pets and 5 between attacks,
  per person.

The whole history is replayed from the issues on every run, so there is no save file. To undo a
press, reopen its issue and close it as **not planned**, or add the `hidden` label.

## Guestbook

Clicking the guestbook board (or the "sign the guestbook" link) opens an issue form. The workflow
thanks the visitor, closes the issue and puts them on the board. Remove a signature the same way as
a button press.

## IT help requests

The "ask me for IT help" link opens an issue form (labelled `it-help`) that warns people not to post
private info. These issues stay open for you to answer.

## Daily wild encounter

A different IT monster appears in the banner's dialog box every day. They're listed in
`scripts/lib/monsters.mjs`; set `"encounters": false` to turn them off.

## Activity clock

Shows which hours and weekdays you commit most, using each commit's own time zone, and gives you a
class: NIGHT OWL, EARLY BIRD, DAY WALKER or EVENING HACKER.

## Coding time (WakaTime)

This panel appears once WakaTime is connected:

1. Sign up at wakatime.com and install its plugin in your editor (VS Code: search "WakaTime" in
   Extensions, then paste your API key when it asks).
2. Copy your secret API key from wakatime.com/settings/api-key.
3. In this repo go to **Settings → Secrets and variables → Actions → New repository secret**, name
   it `WAKATIME_API_KEY` and paste the key.
4. Run the workflow from the Actions tab (or wait for the daily run).

## Preview locally

```bash
DEMO=1 OUT_DIR=preview node scripts/build.mjs
```

Add `DEMO_LEVEL=20` or `DEMO_SEASON=winter` to preview evolutions and themes.
